# AGENTS.md

Guidance for AI coding agents working in this repository. Keep it accurate when
you change structure, commands, or conventions.

## Commands

Run from the repository root unless noted.

- Install: `npm install`
- Dev (all): `npm run dev`
- Lint: `npm run lint`
- Typecheck: `npm run typecheck` (builds `@repo/contracts` first)
- Test: `npm run test`
- Build: `npm run build`
- Single test file: `npm run test -w @repo/server -- test/unit/<path>.spec.ts`
  or `npm run test -w @repo/client -- test/<path>.spec.tsx`
- Migrations: `npm run db:generate`, `npm run db:migrate`
- Seed admin: `npm run seed:admin`
- Server e2e (needs a database and `.env`): `npm run test:e2e -w @repo/server`,
  `npm run test:e2e:pokemon -w @repo/server`

After any change, run `npm run typecheck` and the relevant test file; run the
full `npm run test` before finishing.

## Layout

- `apps/client` — React client (`@repo/client`).
- `apps/server` — NestJS API (`@repo/server`).
- `packages/contracts` — shared zod schemas and types (`@repo/contracts`).
- `packages/tsconfig`, `packages/eslint-config` — shared presets.
- `docs/adr` — architecture decisions. Read the relevant ADR before changing an
  area it covers.

## Architecture rules

- **Shared contracts.** Request/response shapes live in `@repo/contracts` and are
  consumed by both apps. Do not duplicate a wire shape in either app.
- **Pure domain, effectful shell.** `apps/server/src/domain/**` is pure and
  returns `Result<T, DomainError>`; it must not import Nest, Drizzle, Effect, or
  perform I/O. `apps/server/src/modules/**` performs effects.
- **Effect at the service boundary only.** Follow `docs/adr/0001-effect-ts-adoption.md`.
  Services that do I/O expose `Effect.Effect<A, E, never>`; resolvers/controllers
  adapt with `runGraphQL`. Do not mix promise and Effect styles in one module.
- **Error contract.** Errors carry a `code` from `@repo/contracts` and are
  localized by code, never by `message`. See `docs/contracts/errors.md`.
- **Authentication and RBAC.** Permissions are `resource:action` strings defined
  in `apps/server/src/auth/rbac.ts`. Guard server operations with
  `@UserHasPermission` and filter client navigation with
  `filterNavGroupsByPermission`.

## Conventions

- TypeScript strict mode; ESM throughout; server imports use explicit `.ts`
  extensions (rewritten to `.js` on build).
- Follow the existing vertical-slice shape for a new server feature: domain
  (pure) → module (service + resolver/controller + SDL + types) → contract in
  `@repo/contracts` → tests → client API function → client route/components.
- Tests assert external behavior at a seam: the GraphQL/REST boundary for the
  server, contract parsing for `@repo/contracts`, rendered output for the client.
  Prefer existing seams over new ones.
- Do not commit secrets. `.env` is ignored; update `.env.example` when adding a
  variable.
- `apps/client/src/routeTree.gen.ts` is generated by the TanStack Router plugin
  on dev/build; it is committed so typecheck works without a build.

## Definition of done

`npm run lint`, `npm run typecheck`, and `npm run test` all pass, and any new
behavior has a test at an existing seam.
